# Góc thiên nhiên — Responsive Photo Gallery

## Tệp trong bài
- `index.html`: trang thư viện ảnh
- `css/style.css`: bố cục mobile-first và 4 media queries
- `images/`: 8 ảnh SVG nằm sẵn trong dự án, có thể dùng offline

## Những điểm đã làm theo hướng dẫn
- Đã thay đổi ảnh và nội dung văn bản trong trang.
- Mỗi ảnh có văn bản thay thế `alt` mô tả nội dung.
- CSS responsive có 4 breakpoint: 576px, 768px, 992px, 1200px.
- Lưới ảnh tự đổi từ 1 cột trên điện thoại sang 2, 3 và 4 cột trên màn hình rộng.
- Có liên kết bỏ qua đến nội dung chính và hỗ trợ `prefers-reduced-motion`.

## Kiểm tra trước khi nộp
1. Mở `index.html` trong trình duyệt.
2. Kiểm tra tại các độ rộng dưới 576px, 576–767px, 768–991px, 992–1199px và từ 1200px.
3. Chạy HTML Validator: https://validator.w3.org/
4. Chạy WAVE: https://wave.webaim.org/
5. Đưa các tệp đã giải nén lên GitHub repository của bạn và bật GitHub Pages nếu cần gửi đường dẫn trực tiếp.
6. Hoàn thành phần đánh giá ngang hàng theo hướng dẫn môn học.
